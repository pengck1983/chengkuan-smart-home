# 成宽物联网域名规划

| 域名 | 当前用途 | 后续安排 |
|---|---|---|
| `chengkuan-iot.cn` | 主域名 | 成宽项目总入口 |
| `api.chengkuan-iot.cn` | 小智业务 API | 小程序和网页控制台共用 |
| `home.chengkuan-iot.cn` | 预留 | 智慧小家网页控制台 |
| `spring.chengkuan-iot.cn` | 预留 | 接触网弹簧补偿监控 |

所有子域名可以先解析到同一台 ECS，由 Nginx 按域名转发到不同服务。未来拆分服务器时，只需修改对应子域名的 DNS 记录。

建议端口分配：小智 API 使用本机 `127.0.0.1:3000`，小智 MCP 内部 API 使用 `127.0.0.1:3001`；后续项目分配新的本机端口，并继续只通过 Nginx 的 80/443 对外访问。
